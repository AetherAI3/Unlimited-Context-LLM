6 · The caps & why this isn't the ceiling

🧠 Context caps (engine feature)

  • Overpool 300 MiB/session (env CODEPRO_SESSION_CAP_BYTES, 50 MiB–2 GiB).
  • TurboVec 8-bit quantised encode (~4× smaller, recall kept).
  • OpenMythos + UnlimitedContext grounding + overpool.
  • Atlas grounding (new lever): VPS5 atlas holds astropy/sympy/sklearn/scipy/pandas API docstrings = SWE-lite libs. Wired; its 18-inst score is infra-stuck — lift TBD.

💰 Run caps (why N=180, not 300)

  • Stopped ~180/300: a hung request stalled the old proc (now fixed: 180s HTTP timeout + per-instance deadline).
  • Output tokens now capped (4096) — was defaulting to 65k (cost + 402s).
  • OpenRouter key drained by the run — top up to finish 300 + validate the empty fix.
Status / blockers: (1) OpenRouter key needs a top-up (we spent its credit running the bench) before the empty-patch validation, full-300, or atlas score can run. (2) Atlas probe score is infra-stuck on VPS5 Docker churn — re-score on a quiet box. Everything is coded + tested; these are external, not code.
